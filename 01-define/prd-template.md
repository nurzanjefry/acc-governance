# Product Requirements Document (PRD) — Template

**Purpose:** Define what you're building, why, and for whom.

## Sections to Include

### 1. Problem Statement
What pain point are you solving? Who has it?

### 2. Target Users
Who are the primary users? What are their roles/responsibilities?

### 3. Value Proposition
One-sentence benefit. What makes this better than the status quo?

### 4. Core Scope (v1)
What's the minimum viable product? List 5-10 features.
- Feature 1
- Feature 2
- ...

### 5. Non-Goals
What are you explicitly NOT building in v1? (Prevents scope creep)

### 6. Success Metrics
How will you know this works?
- Metric 1: target value
- Metric 2: target value

### 7. Key Risks
What could go wrong? Document and flag for spec phase.
