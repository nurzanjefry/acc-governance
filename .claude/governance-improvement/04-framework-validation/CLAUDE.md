# Framework Phase 4: Validation (Test on Real Projects)

Test the framework improvements against real projects to verify they work as designed.

## Your Task

Use the framework-validator agent to complete these deliverables:

- **validation-report.md** — Results of running the improved framework on real projects
- **regression-report.md** — Confirm existing projects are unaffected
- **findings.md** — Any issues discovered during validation with proposed fixes

## Exit Criteria

✅ Improvements tested on at least one real project end-to-end
✅ No regressions in existing projects
✅ All findings from validation are resolved or documented as known limitations
✅ Performance is equal or better than prior framework

## Reviewers

- **framework-consistency-reviewer** — Do real-world results match design intent?
- **adoption-readiness-reviewer** — Would a new team succeed with these changes?
- **backward-compatibility-reviewer** — Are existing projects confirmed unaffected?

## Next Phase

Once Phase 4 passes review → move to **05-framework-ship** (migration plan and adoption guide).
