# Framework Phase 5: Ship (Migration Plan & Adoption Guide)

Document how existing projects migrate to the new framework version and how new teams adopt it.

## Your Task

Use the framework-shipper agent to complete these deliverables:

- **migration-guide.md** — Step-by-step instructions for existing projects to adopt improvements
- **adoption-guide.md** — Onboarding guide for teams new to the framework
- **changelog.md** — What changed, why, and what it replaces

## Exit Criteria

✅ Migration guide is tested (someone followed it and succeeded)
✅ Adoption guide covers the full onboarding flow (new team, new project)
✅ Changelog is accurate and complete
✅ All breaking changes have a migration path

## Reviewers

- **adoption-readiness-reviewer** — Can a new team follow this without help?
- **backward-compatibility-reviewer** — Is every breaking change covered?
- **docquality-reviewer** — Are guides clear, complete, and cross-linked?

## Completion

Once Phase 5 passes review → merge improvements to main framework branch.
