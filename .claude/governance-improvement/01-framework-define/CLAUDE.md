# Framework Phase 1: Define (Analyze Flaws & Document Philosophy)

Analyze current framework weaknesses, document design philosophy, and align stakeholders on what needs to change.

## Your Task

Use the framework-definer agent to complete these deliverables:

- **flaw-analysis.md** — Current framework weaknesses (evidence-based, from real projects)
- **philosophy.md** — Core design principles this framework must uphold
- **improvement-roadmap.md** — Prioritized list of improvements with rationale

## Exit Criteria

✅ Each flaw is backed by a concrete example (not theoretical)
✅ Philosophy statements are testable (can verify compliance)
✅ Roadmap is prioritized by impact, not effort
✅ No contradictions between philosophy and proposed improvements

## Reviewers

- **framework-consistency-reviewer** — Do improvements honor core principles?
- **adoption-readiness-reviewer** — Will changes be adoptable by new teams?
- **docquality-reviewer** — Are findings clear and cross-linked?

## Next Phase

Once Phase 1 passes review → move to **02-framework-spec** (design detailed improvements).
